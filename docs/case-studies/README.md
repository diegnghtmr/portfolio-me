# Case-study drafts

Drafts for the six featured case studies (T28, S19). They come only from evidence in each public repository, with a link for every claim.

- **TO CONFIRM** marks a fact only Diego can state, such as his role or a live demo.
- **INFERRED** marks a reading of the evidence that the repository does not say outright.
- No metric, user count or outcome is invented.

Once Diego confirms a draft, its content moves into the site's content collection and the project's `caseStudy` flag in `src/data/projects.ts` turns on.
