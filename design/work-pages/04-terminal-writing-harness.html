01 / Problem

Good writing can still describe the wrong code

An AI agent can write fluent Spanish and still describe a command-line option that doesn’t exist. Style guidance alone won’t catch that mismatch. A separate constraint is deciding which rule applies when multiple skills give different directions.

The harness organizes 16 skills and 93 rules with explicit precedence, and adds a gate for claims about the code.

02 / Architecture

Skill precedence

The entry skill sets the writing task. Base norms establish the shared rules. The tone skill adapts the voice without replacing those norms.

03 / Rationale

Decisions & trade-offs

These comparisons explain the visible design, not the original decision process.

Precedence rather than a flat rule list

Options considered
A flat list of writing rules, or named layers with explicit precedence.
Choice
Give the skills an explicit order.
Consequence
A conflict has a rule for resolution, but each new skill has to fit that order.

Check the code as well as the prose

Options considered
Check writing alone, or also compare claims with the code being described.
Choice
Add a gate for prose that describes code.
Consequence
The check needs the relevant code as context. Passing it is not a substitute for reviewing the explanation.

04 / Verification

Result & next steps
